# What is Distributed system?
- The distributed system is the collection of independent machines which are communicating with each other on a network and work together to  provides some service.
- The distributed system is needed becuase scaling the single server has the bottleneck and it also prevent the single point of failure.
- The Replication of server is example of distrbuted system where we are hosting the replicas of components on multiple servers and have load baclancer which takes req and route it to the least busy server and return response back to user.
- Database sharding where database data is split and hosted on differenct server is also is the example of distributed system.
- In Distributed system we usually use the leader follower architecture.
- Challenges of this are data consistency, network failure etc
