# What is server?
- A server is the machine with public IP address. Where we deploy our services. so clients can request the server and the server returns the response accordingly.
- For example when a client request xyz.com on the browser.
- The browser goes to the DNS with that domain name and the dns resolver resolves the domain name in to the numerical IP address.
- the browser get back the IP address. And than the browser finds the server with tht IP address and route the request to it.
- On server there are multiple process are running. The server finds the correct process using the port and return the response back to the client accordingly.
- The numerical IP address of the server is hard to remember that's we map the human readble domain name with the IP address of the machine.
