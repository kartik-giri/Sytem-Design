# What is Latency?
- The Lantency is the total time taken by the single request to travel from the client to the server and for the response to come back. It is generally measured in milliseconds.
- The Round trip time is alsp used as replacement term for latency.
- for example the landing page takes 200ms to load which means the server took 200 ms to return the page data back to the client.
_ The latency should be low as possible to decrease the load time.

# What is throughput?
- The throughput is the amount of request or unit of work the system can handle per second. It is measured as Resquest per second.
- Every server has limit, which means how many request a server can handle in given session. If the request are high than limit the system can crash or go down.
- High thorughput means system can hangle high number of req per second.
Low Throughput means the system can't handle handle high number of req per second because if there are high number of request comes the system can go down or crash.
